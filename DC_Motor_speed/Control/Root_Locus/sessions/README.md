# Control System Designer sessions

No `.mat` session is included: the MATLAB GUI session must be saved by the project owner.

1. Run `../src/02_analytical_lag_design.m`.
2. In Control System Designer, use **Save Session** and save your own session file here.
3. A session captures GUI state; MATLAB scripts in `../src/` remain the reproducible source of the controller parameters.

The **interactive root-locus tuning** screenshot is an illustrative alternative-gain study. It does not replace the analytically calculated controller stored in the source code.
