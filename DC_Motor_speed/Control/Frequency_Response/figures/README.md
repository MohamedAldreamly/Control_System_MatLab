# MATLAB figures

These seven screenshots were captured from the MATLAB session used for the P, Lag and Lead–Lag frequency-response study. The last screenshot is intentionally zoomed to 0–1.2 s for early transient comparison; **do not infer settling time from its displayed interval**. Use the individually annotated step plots and `stepinfo` to evaluate settling time.
